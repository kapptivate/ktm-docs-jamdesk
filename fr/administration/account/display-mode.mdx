---
title: Mode d'affichage
description: Basculez l'interface en clair, en sombre, ou sur le réglage de votre système.
---

Kapptivate s'ouvre en clair. Si vous surveillez des monitorings tard le soir, si vous travaillez à côté d'un écran mural, ou si vous préférez simplement un bureau sombre, vous pouvez basculer toute l'interface en sombre depuis les préférences de votre compte.

## Basculer l'interface en sombre

1. Cliquez sur le nom de votre workspace en haut de la barre latérale et sélectionnez **Settings**
2. Ouvrez **Preferences** sous My account
3. Dans le menu d'ancrage à gauche, cliquez sur **Display mode**
4. Sélectionnez **Dark**

L'interface change au moment où vous cliquez. Il n'y a rien à enregistrer : le bouton **Save changes** couvre le format de date et la langue de cette page, pas le mode d'affichage.

## Les trois options

| Option | Ce que vous obtenez |
| --- | --- |
| **Light** | Le réglage par défaut. Une interface claire, quel que soit le réglage de votre ordinateur. |
| **Dark** | Une interface sombre, quel que soit le réglage de votre ordinateur. |
| **Auto** | Kapptivate suit votre système d'exploitation. |

Auto lit le réglage d'apparence de votre système : **Réglages Système > Apparence** sur macOS, **Paramètres > Personnalisation > Couleurs** sur Windows. Passez votre système en sombre pendant que Kapptivate est ouvert et l'interface suit aussitôt, sans rechargement.

## Votre choix reste sur ce navigateur

Le mode d'affichage est stocké dans le navigateur où vous le réglez, pas sur votre compte Kapptivate. Ouvrez l'application sur un autre ordinateur, dans un autre navigateur ou dans une fenêtre privée, et elle redémarre en clair. Réglez-le une fois dans chaque navigateur depuis lequel vous travaillez. Effacer les données de navigation du site le réinitialise également.

<Tip>
Choisissez **Auto** dans chaque navigateur que vous utilisez, et votre système d'exploitation décide partout, une bonne fois pour toutes.
</Tip>

## Les écrans muraux gardent leur propre bascule

[Status Details](/fr/monitoring/status-details) dispose d'un mode TV avec sa propre bascule jour / nuit dans la barre du haut. Cette bascule l'emporte sur votre mode d'affichage tant que la page reste en mode TV : un écran mural en clair et une interface sombre pour vous cohabitent donc sans conflit. Le choix voyage dans l'URL de la page, si bien qu'un lien épinglé sur un écran se rouvre avec le thème enregistré. Quittez le mode TV et la page revient à votre mode d'affichage.

Vos autres réglages personnels, le format de date et d'heure et la langue de l'interface, se trouvent sur la même page : voir [Préférences](/fr/administration/account/preferences).
