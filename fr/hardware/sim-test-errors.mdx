title: Messages d'erreur des tests SIM
sidebarTitle: Erreurs des tests SIM
description: Ce que veut dire chaque message d'erreur d'un test SIM, de l'USSD et du SMS aux appels, à la data et à la technologie réseau, et que faire dans chaque cas.
---

Une SIM peut sembler saine et faire quand même échouer un test. Dans ce cas, cherchez le message du résultat dans les tableaux de cette page : chacun dit d'où vient l'échec et ce qu'il faut faire. Si c'est la SIM elle-même qui paraît en défaut dans la plateforme, commencez plutôt par [Dépanner une carte SIM](/fr/hardware/sim-troubleshooting).

Les messages ci-dessous sont ceux qu'émet le robot, cités mot pour mot. Tout autre texte est la réponse du réseau lui-même : un menu, un solde, ou une erreur de passerelle comme `USSDC: ESME fault.` ou `Service not available`. Dans ce cas, la SIM fonctionne et le réseau a répondu. Transmettez le texte à l'équipe qui gère le service appelé par ce code.

## USSD

| Message | Ce qu'il faut faire |
|---|---|
| `Connection problem or invalid MMI code (+CME ERROR: 100)` | Le réseau a rejeté la requête. Si plusieurs SIM échouent à partir de la même minute, la plateforme USSD est en cause : pour le confirmer, rejouez le code sur une autre SIM du site en [live session](/fr/tests/live-session). Si une seule SIM est touchée, redémarrez son slot, puis testez la carte dans un téléphone. |
| `Connection problem or invalid MMI code (+CME ERROR: 258)` | La SIM refuse les requêtes USSD. Redémarrez le slot, puis faites vérifier le profil de la ligne par votre équipe réseau. |
| `No network service (+CME ERROR: 30)` | Regardez la colonne **Network**. Si la SIM est enregistrée, la cause est côté réseau. |
| `Call barred (+CME ERROR: 257)` | Levez l'interdiction d'USSD sur la ligne. |
| `Network Timeout (+CUSD 5)`, `no ussd response received from network` ou `Ussd session closed by operator (+CUSD:2)` | Le réseau n'a pas répondu, ou a fermé la session avant la fin : mauvaise couverture, licence USSD expirée ou serveur USSD surchargé. Transmettez à l'équipe qui gère votre plateforme USSD le code, l'heure et le numéro de la SIM. |
| `Wrong USSD code format` | Corrigez le champ **Command** du test. |

## SMS

| Message | Ce qu'il faut faire |
|---|---|
| `SMS not received.` | Testez la carte dans un téléphone. Si elle ne reçoit rien non plus, vérifiez la ligne et le SMSC. Si tous les tests SMS d'un robot échouent en même temps, écrivez à support@kapptivate.com : une horloge décalée de plus de 30 secondes fait échouer tous les tests SMS du robot. Le reste de ses tests fonctionne tant que le décalage reste sous deux minutes. |
| `Received SMS was not the expected one.` | Comparez le SMS au champ **Expected Message** du test. Le service a peut-être changé son message, ou répondu par une erreur, un solde vide par exemple. |
| `failed to send sms` | Vérifiez le crédit de la ligne, puis son SMSC. |

## Appels

| Message | Ce qu'il faut faire |
|---|---|
| `cannot place call to <NUMBER>` | Vérifiez que la SIM appelante est enregistrée et qu'elle a du crédit. |
| `call was correctly emitted but was suddenly stopped` | Soit la SIM n'a plus de crédit, soit elle n'est pas autorisée à appeler ce numéro (numéros courts, ou itinérance). |
| `timeout call not pick up` | Vérifiez que la SIM appelée est enregistrée. |
| `timeout no call received` | Lisez le résultat du côté appelant, et vérifiez le numéro qu'il compose. |

## Data

| Message | Ce qu'il faut faire |
|---|---|
| `No internet after PDP activation` | Le forfait data est épuisé ou a expiré : rechargez la ligne. |
| `Failed to activate PDP context (timeout while waiting cellular network attachment)` | La SIM n'est pas attachée au réseau. Reprenez le [dépannage de la SIM](/fr/hardware/sim-troubleshooting). |
| `Failed to activate PDP context (no 'APN' specified)` | Dans le test, réactivez **Use default APN credentials**, ou renseignez **APN Name**. |
| `Failed to activate PDP context (Unspecified reason)` | Vérifiez l'APN et l'abonnement data de la ligne. |

## Technologie réseau

Le robot change de technologie avant d'exécuter l'action. Ces messages apparaissent donc en premier.

| Message | Ce qu'il faut faire |
|---|---|
| `failed to change network technology: sim not registered` ou `failed to change network technology: timeout while waiting network registration` | La SIM n'est pas enregistrée sur la technologie demandée. Réglez **Access technology** sur **Default**, sauf si le test vérifie volontairement une technologie. Si l'erreur persiste avec **Default**, reprenez le [dépannage de la SIM](/fr/hardware/sim-troubleshooting). |
| `failed to change network technology: ERROR` | Redémarrez le slot. Si l'erreur persiste, écrivez à support@kapptivate.com. |

## Robot et test

| Message | Ce qu'il faut faire |
|---|---|
| `Robot unreachable` | Le robot est **Offline** : suivez [Dépanner un robot Offline](/fr/hardware/network-troubleshooting). |
| `SIM timeout` | Le slot n'a pas répondu dans le délai, de quatre minutes par défaut. Redémarrez le slot. Si l'erreur revient, écrivez à support@kapptivate.com. |
| `Owner <NUMBER> not recognized` | Aucune SIM de votre espace de travail ne porte ce numéro en ce moment. Modifiez le test ou le monitor pour sélectionner une SIM disponible. Après un remplacement, vous pouvez aussi attribuer ce numéro à la nouvelle SIM, en suivant [Remplacer une SIM](/fr/hardware/swap-sim). |
