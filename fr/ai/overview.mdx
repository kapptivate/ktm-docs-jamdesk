Les tests UI cassent pour de mauvaises raisons : un changement de DOM renomme un sélecteur, un code à usage unique arrive dans une boîte de réception, un bug visuel passe à travers une assertion en correspondance exacte. Kapptivate intègre l'IA dans le cycle de vie des tests pour absorber précisément ce type de fragilité, tout en vous laissant le contrôle sur son périmètre d'action.

Vous décidez de l'empreinte : l'IA peut être complètement désactivée, limitée à des étapes individuelles, ou piloter chaque sélecteur, par test, avec une [stratégie](/fr/ai/selectors#stratégies-ia) qui définit quand elle s'engage.

## Où vous le contrôlez

- **À la création** : la case **Utilisation de l'IA** active l'IA dès la première étape ([Créer un test](/fr/tests/create)).
- **Par test** : le toggle **Activer l'IA** et la stratégie dans **Paramètres du test > Utilisation de l'IA** ([Test builder](/fr/tests/builder)).
- **Par étape** : le toggle **Activer l'IA pour cette étape** surcharge le paramètre du test là où vous en avez besoin.
