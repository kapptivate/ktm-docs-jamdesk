Lister les tests, avec filtrage optionnel par operator et produit

## Utilisation

```bash
ktm tests list [flags]
```

## Exemples

```bash
# Lister tous les tests d'un produit
ktm tests list --operator my-operator --product my-operator~my-product

# Rechercher par sous-chaîne du nom
ktm tests list --operator my-operator --name login

# Inclure les tests archivés
ktm tests list --operator my-operator --archived true

# Filtrer par tags
ktm tests list --operator my-operator --tags smoke,regression

# Paginer les résultats
ktm tests list --operator my-operator --page 2 --page-size 50
```

## Flags

| Flag | Type | Défaut | Description |
| --- | --- | --- | --- |
| `--archived` | string |  | Inclure les tests archivés : true, false (défaut : false = non archivés uniquement) |
| `--fields` | string |  | Restreindre la réponse JSON à ces champs (liste blanche séparée par des virgules) |
| `--name` | string |  | Filtrer par nom de test (correspondance partielle, insensible à la casse) |
| `--operator` | string |  | Slug de l'operator (depuis 'operators list') pour limiter les résultats |
| `--ordering` | string |  | Trier par champ : name, created, modified (préfixez avec - pour l'ordre décroissant) |
| `--page` | string |  | Numéro de page à récupérer (défaut : 1) |
| `--page-size` | string |  | Nombre de résultats par page (défaut : 20 ; passez une valeur plus élevée pour en récupérer davantage) |
| `--product` | string |  | Slug du produit (depuis 'products list', format : operator~product) pour limiter les résultats |
| `--tags` | string[] |  | Liste de tags séparés par des virgules pour filtrer (ex. --tags smoke,regression) |

## Détails

Liste les scénarios de test définis sur la plateforme.

Les tests appartiennent à un produit (qui appartient lui-même à un operator). Utilisez --operator et
--product pour affiner les résultats. Les tests non archivés sont retournés par défaut.

L'"id" du test peut être utilisé dans les fichiers de configuration CI pour déclencher une exécution via "ci run".

Champs de sortie JSON : id, name, product, owner, tags, archived, is_valid, status, kind, created, modified
Colonnes du tableau :   ID, NAME, PRODUCT, STATUS, KIND, ARCHIVED
