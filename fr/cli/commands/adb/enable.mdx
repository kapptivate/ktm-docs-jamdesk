Activer le bridge ADB sur un agent (sans redémarrage de l'agent)

## Utilisation

```bash
ktm adb enable [flags]
```

## Exemples

```bash
ktm adb enable --agent phone-hub-01
```

## Détails

Démarre le bridge ADB sur un agent pour que ses téléphones acceptent 'ktm adb connect'. Le basculement est éphémère : après un redémarrage de l'agent, c'est de nouveau la configuration propre de l'agent qui décide.
