Désactiver le bridge ADB sur un agent (met fin aux connexions actives)

## Utilisation

```bash
ktm adb disable [flags]
```

## Exemples

```bash
ktm adb disable --agent phone-hub-01
ktm adb disable --agent phone-hub-01 --confirm
```

## Flags

| Flag | Type | Défaut | Description |
| --- | --- | --- | --- |
| `--confirm` | boolean |  | Exécuter la désactivation (sans ce flag, affiche un aperçu) |

## Détails

Arrête le bridge ADB sur un agent. Quiconque est connecté à l'un de ses téléphones via 'ktm adb connect' est déconnecté et les téléphones sont libérés. Le basculement est éphémère : après un redémarrage de l'agent, c'est de nouveau la configuration propre de l'agent qui décide.
