Afficher les téléphones, l'état du bridge ADB de leur agent et qui est connecté

## Utilisation

```bash
ktm adb status [flags]
```

## Exemples

```bash
ktm adb status
ktm adb status --all
ktm adb status --output json
```

## Flags

| Flag | Type | Défaut | Description |
| --- | --- | --- | --- |
| `--all` | boolean |  | Inclure les téléphones non configurés ou non rattachés à un agent |

## Détails

Une ligne par téléphone Android : l'agent qui l'héberge, l'état (activé ou non)
du bridge ADB de cet agent et, quand quelqu'un est connecté via
'ktm adb connect', qui détient le téléphone et depuis quand.

Valeurs de la colonne BRIDGE : on, off (activez avec 'ktm adb enable'), offline
(agent injoignable), unknown (l'agent n'expose pas de configuration à distance).

BRIDGE et IN USE BY décrivent des sessions adb, une question distincte de la
disponibilité plateforme affichée par 'ktm resources list' : un téléphone peut y
être Available alors que quelqu'un le détient ici.

Les téléphones non configurés ou non rattachés à un agent sont omis, puisque
rien ne peut s'y connecter ; --all les liste aussi.
