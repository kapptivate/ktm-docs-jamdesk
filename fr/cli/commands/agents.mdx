## Détails

Gérer les agents (le matériel/logiciel qui exécute les ressources). Portée opérateur.

Trois types d'agents :
  cellular    Passerelles GSM avec des slots de cartes SIM
  ethernet    Agents web autonomes (pas de slots, capacité = max de tests parallèles)
  smartphone  Hubs téléphoniques avec smartphones connectés

Chaque commande ci-dessous identifie un agent avec --agent, qui accepte soit le
nom d'hôte de l'agent, soit son UUID (les colonnes HOSTNAME et UUID de
'agents list').

Tâches courantes :
  ktm agents list --operator &lt;slug&gt; --type smartphone      → santé du parc
  ktm agents get --agent &lt;hostname|uuid&gt;                   → un agent en détail, avec ses slots
  ktm agents adapters list --agent &lt;hostname|uuid&gt;         → ses fonctionnalités contrôlables à chaud
  ktm agents adapters get &lt;name&gt; --agent &lt;hostname|uuid&gt;   → ce que cette fonctionnalité expose : paramètres, types, ce qui est modifiable
  ktm agents adapters set &lt;name&gt; KEY=VALUE --agent &lt;hostname|uuid&gt; [--resource &lt;serial&gt;]
                                                           → changer un paramètre, pour l'agent ou un seul téléphone
  ktm agents adapters enable|disable &lt;name&gt; --agent &lt;hostname|uuid&gt;
                                                           → démarrer/arrêter une fonctionnalité, sans redémarrage de l'agent
  ktm agents reboot --agent &lt;hostname|uuid&gt; --confirm      → redémarrer un agent
  ktm agents maintenance --agent &lt;hostname|uuid&gt; --enable --confirm
                                                           → arrêter la planification de tests dessus

Les changements d'adaptateurs à chaud, basculements comme paramètres (par
exemple le bridge ADB, nom d'adaptateur adb_bridge), sont éphémères : après un
redémarrage de l'agent, c'est de nouveau la configuration propre de l'agent qui
décide. Pour le bridge ADB, 'ktm adb status|enable|disable' sont les raccourcis
centrés téléphone.

Utilisez 'resources list' pour obtenir les informations d'appareils au niveau produit.
