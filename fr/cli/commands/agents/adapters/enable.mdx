Démarrer un adaptateur contrôlable sur un agent (sans redémarrage de l'agent)

## Utilisation

```bash
ktm agents adapters enable <adapter> [flags]
```

## Exemples

```bash
ktm agents adapters enable adb_bridge --agent phone-hub-01
```

## Arguments

| Argument | Requis |
| --- | --- |
| `adapter` | Oui |

## Détails

Démarre un adaptateur sur un agent, sans redémarrer l'agent. Activer un
adaptateur déjà en cours d'exécution rapporte un succès et ne change rien.

Le changement est éphémère : après un redémarrage de l'agent, c'est de nouveau
la configuration propre de l'agent qui décide.
