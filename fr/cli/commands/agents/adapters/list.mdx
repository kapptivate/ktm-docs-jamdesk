Lister les adaptateurs contrôlables d'un agent et leur état

## Utilisation

```bash
ktm agents adapters list [flags]
```

## Exemples

```bash
ktm agents adapters list --agent phone-hub-01
ktm agents adapters list --agent phone-hub-01 --output json
```

## Détails

Affiche chaque fonctionnalité de cet agent pilotable pendant qu'il tourne : si
elle est en cours d'exécution, si elle démarre avec l'agent (BOOT), combien de
sessions actives elle sert, si elle accepte des paramètres par téléphone, et les
paramètres en vigueur au niveau de l'agent.

Utilisez 'ktm agents adapters get &lt;adapter&gt;' pour voir ce que l'on peut
demander à un adaptateur listé.
