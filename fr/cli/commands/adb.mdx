## Détails

Connectez Android Studio ou le CLI ADB aux téléphones hébergés sur des agents distants.

Fonctionnement : chaque agent exécute un « bridge ADB » qui expose ses téléphones
pour le débogage à distance. Le bridge est livré désactivé : activez-le par agent
(instantanément, sans redémarrage de l'agent), connectez-vous, puis désactivez-le
quand vous avez terminé :

  ktm adb status                              → chaque téléphone : agent, bridge activé/désactivé, détenteur actuel
  ktm adb enable --agent &lt;hostname&gt;           → activer le bridge (retour à la config de l'agent au redémarrage)
  ktm adb connect [serial]                    → tunneler un téléphone vers votre serveur ADB local (propose l'activation si désactivé)
  ktm adb disable --agent &lt;hostname&gt; --confirm → désactiver le bridge et libérer ses téléphones

Le tunnel est une connexion TLS sécurisée sur le port 443. L'appareil s'enregistre
automatiquement auprès de votre serveur ADB local et apparaît donc dans Android
Studio comme un téléphone branché sur votre ordinateur.

Un seul utilisateur peut détenir un téléphone donné à la fois ; une seconde
connexion est refusée en nommant le détenteur actuel, jusqu'à ce qu'il se
déconnecte. Le téléphone est libéré dès que vous vous déconnectez.
'ktm adb enable|disable' sont des raccourcis du contrôle générique des
adaptateurs à chaud : voir 'ktm agents adapters --help'.
