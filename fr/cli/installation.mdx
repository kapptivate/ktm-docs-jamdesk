`ktm` est distribué sous la forme d'un binaire unique et autonome pour Linux, macOS et Windows. Une fois placé sur votre PATH, vous vous connectez via votre navigateur (ou une clé API) et vous êtes prêt.

## Installer ktm

Exécutez la commande correspondant à votre plateforme :

<Tabs>
  <Tab title="macOS / Linux">

```bash
curl -fsSL https://artefacts.kapptivate.com/ktm/install.sh | bash
```

  </Tab>
  <Tab title="Windows">

```powershell
irm https://artefacts.kapptivate.com/ktm/install.ps1 | iex
```

  </Tab>
</Tabs>

Le script télécharge la dernière version stable de `ktm`, vérifie son checksum et l'ajoute à votre PATH. Définissez `KAPPTIVATE_VERSION=1.5.0` pour fixer une version spécifique.

Les préversions sont publiées sur le canal **beta**. Définissez `KAPPTIVATE_CHANNEL=beta` pour installer la dernière :

<Tabs>
  <Tab title="macOS / Linux">

```bash
curl -fsSL https://artefacts.kapptivate.com/ktm/install.sh | KAPPTIVATE_CHANNEL=beta bash
```

  </Tab>
  <Tab title="Windows">

```powershell
$env:KAPPTIVATE_CHANNEL = "beta"; irm https://artefacts.kapptivate.com/ktm/install.ps1 | iex
```

  </Tab>
</Tabs>

Vérifiez l'installation :

```bash
ktm --version
```

## Authentification

Pour un usage interactif, connectez-vous via votre navigateur (OAuth) :

```bash
ktm login
ktm status
```

`ktm login` ouvre votre navigateur pour une connexion sécurisée et stocke la session dans le trousseau de votre système. `ktm whoami` affiche qui est connecté, et `ktm logout` met fin à la session.

Pour la CI et les scripts, utilisez plutôt une clé API. `ktm` la lit depuis la variable d'environnement `KAPPTIVATE_API_KEY` :

```bash
export KAPPTIVATE_API_KEY="your-key"
ktm status
```

Quand les deux sont présentes, la clé API a la priorité. `ktm status` vérifie la connectivité, l'authentification et la version du CLI en un seul appel, et nomme le mode d'authentification réellement utilisé. Un résultat propre signifie que vous êtes prêt.

<Tip>
  En CI, stockez la clé comme secret et exposez-la en tant que `KAPPTIVATE_API_KEY`. Ne la codez jamais en dur dans un fichier de workflow.
</Tip>
