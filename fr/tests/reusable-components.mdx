Un **composant réutilisable** est un test que vous construisez une seule fois et intégrez dans d'autres tests comme brique de base : un flux de connexion, une fermeture de bandeau de cookies, une séquence de navigation. Au lieu de copier les mêmes étapes dans chaque test, vous les maintenez à un seul endroit et les référencez partout.

![L'onglet Composants réutilisables avec les pastilles d'utilisation, le nombre d'étapes et les icônes de connexion avec code couleur](/images/components-list.webp)

## Comment ça fonctionne

Un composant réutilisable est créé comme n'importe quel autre test, mais il se trouve dans son propre onglet **Composants réutilisables**, à côté de Tests et Campagnes de tests. Quand un autre test référence un composant, les étapes du composant s'exécutent en ligne comme partie intégrante de ce test.

Mettez à jour un composant une seule fois et chaque test qui l'utilise prend en compte la modification : corrigez un flux de connexion à un seul endroit et tous les tests dépendants restent corrects.

## En créer un

Il existe deux façons de créer un composant :

**Depuis zéro** : ouvrez l'onglet **Composants réutilisables** dans la liste des tests et créez-le comme un test normal : choisissez un canal, définissez un point de départ, et ajoutez des étapes. Une fois sauvegardé, il est disponible pour être inséré dans d'autres tests du même produit.

**Depuis un test existant** : dans le test builder, ouvrez le menu d'un groupe d'étapes et choisissez **Créer un composant réutilisable**. Le groupe est publié dans la bibliothèque et devient violet pour indiquer qu'il est désormais partagé. Pour le reconvertir en étapes classiques dans ce test, utilisez **Détacher le composant réutilisable**.

## La liste des composants

L'onglet Composants réutilisables liste chaque composant avec une pastille **Usage** ("Utilisé dans X tests") et un compteur d'**Étapes**. L'icône de connexion à côté du nom est codée par couleur : violet quand le composant est activement utilisé, gris quand rien ne le référence encore.

Les composants sont rangés dans des **collections**, comme les tests. Parcourez-les depuis l'arborescence de l'onglet Composants réutilisables, déplacez-en un avec **Déplacer vers...** depuis son menu, et cherchez dans tout l'arbre. Les mêmes collections apparaissent dans la fenêtre qui insère un composant dans un test : une grosse bibliothèque reste navigable depuis le builder.

Cliquez sur la pastille d'utilisation d'un composant pour ouvrir la fenêtre **Utilisé dans les tests** : elle liste chaque test dépendant avec son créateur et un raccourci **Modifier** directement vers le builder de ce test, pour que vous puissiez évaluer l'impact d'une modification avant de la faire.

## Réutilisation et dépendances

- **Propagation de la validité :** si un composant devient invalide, chaque test qui en dépend est marqué comme invalide jusqu'à ce que le composant soit corrigé. Dans la liste des tests, un triangle rouge signale un test dont une dépendance est cassée.
- **Portée produit :** les composants réutilisables appartiennent à un seul produit. Un test qui contient un composant réutilisable ne peut pas être copié vers un autre produit.
