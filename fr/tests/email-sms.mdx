Les inscriptions, les connexions avec 2FA et les réinitialisations de mot de passe quittent toutes le navigateur à un moment donné : un code arrive par SMS, un lien de confirmation atterrit dans une boîte de réception. Kapptivate ferme cette boucle. Son service de mail et SMS reçoit les vrais messages, et des étapes alimentées par l'IA extraient le code ou le lien dans une variable que vos étapes suivantes utilisent, sans copier-coller manuel, sans règles d'analyse fragiles.

![Un groupe d'étapes enchaînant Code par SMS, Code par email et Lien par email, chacun exposant sa variable extraite](/images/email-sms-steps.webp)

## Les étapes Email & SMS

Ajoutez-les depuis **Ajouter une étape... > Email & SMS** dans le builder. Chaque étape extrait une valeur et la stocke dans une variable (vous pouvez renommer la valeur par défaut) :

| Étape | Entrée | Variable par défaut | Ce que l'IA extrait |
|------|--------|---------------------|---------------------|
| **[Code par SMS](/fr/tests/actions/web/getsmscode)** | Numéro de téléphone pour recevoir le code | `CodeSMS` | Le code de vérification dans le SMS |
| **[Code par email](/fr/tests/actions/web/getemailcode)** | Email pour recevoir le code | `CodeMail` | L'OTP ou le code de vérification dans l'email |
| **[Lien par email](/fr/tests/actions/web/getemaillink)** | Email pour recevoir le lien | `LienMail` | Le lien correspondant à votre intention |

Chaque nom d'étape renvoie à sa page de référence, avec les paramètres et le format JSON. Pour récupérer un message entier au lieu d'une seule valeur, utilisez [Récupérer un mail](/fr/tests/actions/web/getmail). Les mêmes étapes existent pour les [tests smartphone](/fr/tests/actions/smartphone/getmail).

Les étapes attendent l'arrivée du message, puis l'analysent avec l'IA : aucune configuration de format, quelle que soit la formulation ou la mise en page de l'expéditeur.

## Adresses et numéros de téléphone

**L'email** fonctionne immédiatement. Toute adresse sur le domaine `kappti.dev` est une boîte mail de test active, vous pouvez donc en utiliser une nouvelle à chaque exécution : `signup-test@kappti.dev`, `qa-reset@kappti.dev`, ou ce qui convient à votre parcours. Pour garantir une boîte unique à chaque exécution, construisez l'adresse depuis l'onglet **Random** du sélecteur de variables, par exemple `{Random text}@kappti.dev`, afin qu'une inscription n'entre jamais en collision avec une exécution précédente. Voir [Variables dans les tests](/fr/tests/variables) pour les presets aléatoires.

**Les numéros de téléphone** sont rattachés à votre organisation. Pour le moment, demandez à votre account manager de provisionner les numéros dont vos tests SMS ont besoin, puis utilisez-les dans l'étape **Code par SMS**.

## Cibler le bon lien avec Intention

Un email contient souvent plusieurs liens (le lien d'action, mais aussi les pieds de page de désinscription, les logos, les pages d'aide). Sélectionnez une étape **Lien par email** et remplissez le champ **Intention** dans son onglet **Général** pour indiquer à l'IA lequel vous voulez, en langage naturel : "Le lien pour activer mon compte".

## Utiliser les valeurs extraites

Les variables extraites se comportent comme n'importe quelle variable de test. Cliquez sur l'icône `{}` dans le champ d'une étape suivante et sélectionnez-les depuis l'onglet **Dans le test** : naviguez vers `LienMail`, saisissez `CodeSMS` dans le champ 2FA, ajoutez une assertion sur `CodeMail`.

Consultez [Variables dans les tests](/fr/tests/variables) pour tout ce que le sélecteur de variables peut faire.

## Ce que les résultats capturent

Chaque étape Email & SMS se documente lui-même dans le résultat d'exécution :

- **Étapes email** : capturent des captures d'écran de l'email reçu au format mobile, tablette et desktop, pour que vous obteniez aussi une vérification visuelle de vos emails transactionnels.
- **Étapes SMS** : capturent le texte brut du message à côté des variables extraites.
