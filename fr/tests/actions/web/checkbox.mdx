---
title: Cocher une case
description: Étape obsolète qui coche ou décoche une case. Utilisez Clic dans un test web à la place.
---

<Danger>
  **Obsolète.** Cette étape n'apparaît plus dans la palette d'étapes. Les tests existants qui l'utilisent continuent de fonctionner. Pour les nouveaux tests, utilisez [Clic](/fr/tests/actions/web/click) sur la case à cocher. Un clic bascule l'état au lieu de le définir, vérifiez donc le résultat avec [Vérifier l'élément](/fr/tests/actions/web/verifyelement) si nécessaire.
</Danger>

Cochez ou décochez une case. L'étape ne clique que si la case n'est pas déjà dans cet état : le lancer deux fois n'annule donc pas le premier passage.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel de la case à cocher. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé lorsque l'IA est désactivée ou comme sélecteur enregistré. |
| Cocher la case | Non | L'état cible. Par défaut : désactivé (non cochée). |
| Utilisation de l'IA | Non | `inherit` (par défaut, suit la stratégie du test), `smart`, ou `always`. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Temps** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : succès, avertissement ou échec, avec le message d'erreur en cas d'échec.
- **Capture d'écran** : prise après l'exécution de l'étape.
