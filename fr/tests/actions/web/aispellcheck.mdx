---
title: "Vérifier l'orthographe (IA) dans un test web"
sidebarTitle: "Vérification orthographique (IA)"
description: L'IA vérifie le texte visible de la page pour détecter les fautes d'orthographe et de grammaire.
---

Repérez les fautes de frappe et de grammaire de votre interface avant vos utilisateurs. Indiquez à l'étape la langue dans laquelle la page doit être rédigée : elle échoue quand l'IA trouve des fautes, et les liste dans le résultat. Utilisez-la sur les pages riches en texte et pour vérifier chaque version traduite de votre site.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Langue | Oui | La langue dans laquelle le texte visible est censé être rédigé (par exemple `French`). |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Temps** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : échec lorsque l'IA détecte des fautes d'orthographe ou de grammaire dans le texte visible, avec la liste des problèmes dans le résultat.
- **Capture d'écran** : prise pour l'état vérifié, afin que vous puissiez voir exactement ce qui a été contrôlé.
- **Utilisation de l'IA** : le coût IA de la vérification est ajouté à l'exécution.

Pour comprendre le fonctionnement de la vérification et interpréter les résultats, consultez [Vérification orthographique](/fr/ai/spell-check).
