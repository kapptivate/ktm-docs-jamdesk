---
title: "Attendre un délai dans un test web"
sidebarTitle: "Attendre un délai"
description: Mettez un test web en pause pendant une durée fixe, de quelques millisecondes à plusieurs minutes.
---

Utilisez-la quand rien sur la page n'indique que le système est prêt : un traitement backend encore en cours, une limite de débit à respecter, une animation que vous ne pouvez pas intercepter.

<Tip>
  Si vous attendez qu'un élément apparaisse sur la page, utilisez plutôt [Vérifier l'élément](/fr/tests/actions/web/verifyelement). Il continue dès que la condition est remplie au lieu de consommer systématiquement tout le délai.
</Tip>

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Durée | Oui | Durée de la pause. Un nombre suivi d'une unité : `ms`, `s`, ou `m`. Par défaut : `10s`. |

## Résultats et métriques

- **Temps** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape. La durée correspond à la pause configurée.
- **Statut** : succès, sauf si l'exécution est interrompue pendant la pause.
