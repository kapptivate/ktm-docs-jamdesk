L'étape appuie sur les touches comme un utilisateur devant son clavier. Dans le builder, vous les enregistrez dans une petite modale clavier : appuyez sur les touches à envoyer, et elles sont stockées dans l'ordre.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Touches | Oui | Les touches à envoyer, enregistrées dans la modale clavier et envoyées dans l'ordre. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

Cette étape ne cible pas d'élément : les touches vont à l'élément actif de la page (celui qui a le focus). Utilisez d'abord [Clic](/fr/tests/actions/web/click) ou [Saisie de texte](/fr/tests/actions/web/input) pour rendre le bon élément actif.

## Résultats et métriques

- **Temps d'exécution** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : succès, avertissement ou échec, avec le message d'erreur en cas d'échec.
- **Capture d'écran** : prise après l'envoi des touches.
