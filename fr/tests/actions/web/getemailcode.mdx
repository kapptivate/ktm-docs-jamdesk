Utilisez-le pour tester de bout en bout un parcours qui envoie un code à usage unique par e-mail, comme une inscription ou une connexion. L'IA trouve le code dans l'e-mail et le stocke dans une variable. Un step [Fill input](/fr/tests/actions/web/input) le saisit ensuite dans le champ de confirmation.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| E-mail destinataire | Oui | L'adresse de la boîte mail de test qui doit recevoir l'e-mail contenant le code. |
| Variable | Oui | Nom de la variable qui reçoit le code. Par défaut : `MailCode`. |
| Ignorer l'erreur sur ce step | Non | L'exécution continue avec le step suivant si aucun code n'est trouvé. Par défaut : désactivé. |

## Résultats et métriques

- **Variable** : le code extrait est stocké dans la variable, prêt à être saisi dans un champ de confirmation par un step Fill input ultérieur.
- **Temps d'exécution** : début, fin et durée (en secondes). La durée inclut l'attente de l'arrivée de l'e-mail.
- **Statut** : échec si aucun e-mail n'arrive ou si l'IA ne trouve pas de code dedans.
- **Utilisation de l'IA** : le coût IA de l'extraction est ajouté à l'exécution.

Consultez [Email & SMS dans les tests](/fr/tests/email-sms) pour savoir comment les boîtes mail de test fonctionnent.
