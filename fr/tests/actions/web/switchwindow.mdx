Utilisez-le quand le parcours ouvre un nouvel onglet ou une popup : une page de paiement, une popup de connexion (OAuth), un aperçu de document. Le step bascule sur l'onglet ouvert dont le titre ou l'URL correspond au texte que vous lui donnez.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Nom de l'onglet ou URL | Oui | Texte comparé au titre et à l'URL des onglets ouverts. Le premier onglet correspondant devient l'onglet actif. Supporte les variables. |
| Ignorer l'erreur sur ce step | Non | L'exécution continue avec le step suivant si aucun onglet ne correspond. Par défaut : désactivé. |

## Résultats et métriques

- **Temps** : début, fin et durée (en secondes) enregistrés dans le résultat du step.
- **Statut** : échec si aucun onglet ouvert ne correspond au nom ou à l'URL.
- **Capture d'écran** : prise dans l'onglet nouvellement actif.
