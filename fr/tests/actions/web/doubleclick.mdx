---
title: "Double-cliquer sur un élément dans un test web"
sidebarTitle: Double clic
description: Double-cliquer sur un élément localisé par une description IA ou un sélecteur manuel.
---

Utilisez-la quand un simple clic ne suffit pas : ouvrir un élément dans une liste de type gestionnaire de fichiers, passer une cellule en mode édition, ou déclencher toute autre action que la page prévoit au double-clic.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel de l'élément. L'IA l'utilise pour trouver l'élément. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé quand l'IA est désactivée ou comme sélecteur enregistré. |
| Utilisation de l'IA | Non | `inherit` (par défaut, suit la stratégie du test), `smart` ou `always`. |
| Activer l'IA | Non | Quand désactivé, seul le sélecteur manuel est utilisé. Par défaut : activé. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Temps d'exécution** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : succès, avertissement ou échec, avec le message d'erreur en cas d'échec.
- **Capture d'écran** : prise après le double-clic.
- **Utilisation de l'IA** : si l'IA a localisé l'élément, le sélecteur corrigé est enregistré sur le test et le coût IA est ajouté à l'exécution.
