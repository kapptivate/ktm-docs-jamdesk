---
title: "Vérifier un élément dans un test web"
sidebarTitle: "Vérifier l'élément"
description: Vérifiez qu'un élément est (ou n'est pas) affiché, cliquable, activé ou présent.
---

Vérifiez l'état d'un élément : la bannière de confirmation est affichée, le bouton Envoyer est cliquable, le spinner de chargement a disparu. L'étape attend que la condition soit remplie et échoue si elle ne l'est jamais dans le temps d'attente imparti. C'est la principale étape de vérification pour les tests web, et une alternative robuste aux délais fixes.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel de l'élément à vérifier. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé lorsque l'IA est désactivée ou comme sélecteur enregistré. |
| Condition | Oui | **est** (`is`) ou **n'est pas** (`is not`). "n'est pas" définit `reverse: true` sur l'état choisi. |
| État | Oui | L'état à vérifier. Par défaut : `displayed`. `exist` est libellé "présent" dans le builder : l'élément fait partie de la page, visible ou non. |
| Temps d'attente max. | Non | Durée d'attente avant l'échec, en secondes. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

Les quatre états :

- **affiché** : l'élément est visible à l'écran.
- **cliquable** : l'élément est visible et peut recevoir un clic ou un appui.
- **activé** : l'élément est actif (non désactivé).
- **présent** : l'élément fait partie de la page, même s'il est masqué.

## Résultats et métriques

- **Temps** : début, fin et durée (en secondes). La durée indique combien de temps la condition a mis à devenir vraie, un signal utile en soi.
- **Statut** : succès dès que la condition est remplie, échec si le temps d'attente expire.
- **Capture d'écran** : prise pour l'état vérifié.
