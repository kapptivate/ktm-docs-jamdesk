title: "Faire défiler la page dans un test web"
sidebarTitle: "Scroll"
description: "Faites défiler une page web jusqu'à ce qu'un élément soit visible, pour que les étapes suivantes atteignent le contenu plus bas."
---

Utilisez-la avant d'interagir avec du contenu qui n'est pas encore à l'écran, ou pour vérifier que les sections qui ne se chargent qu'une fois atteintes (chargement différé) s'affichent bien. Les réglages de placement décident où l'élément se retrouve à l'écran.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel de l'élément vers lequel défiler. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé quand l'IA est désactivée ou comme sélecteur enregistré. |
| Comportement du défilement | Non | `auto` (par défaut), `smooth` ou `instant`. |
| Positionnement vertical | Non | Position verticale de l'élément : `start`, `center` (par défaut), `end` ou `nearest`. |
| Positionnement horizontal | Non | Position horizontale de l'élément : `start`, `center` (par défaut), `end` ou `nearest`. |
| Utilisation de l'IA | Non | `inherit` (par défaut, suit la stratégie du test), `smart` ou `always`. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Temps d'exécution** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : succès, avertissement ou échec, avec le message d'erreur en cas d'échec.
- **Capture d'écran** : prise après l'exécution de l'étape, montrant la nouvelle position.
- **Utilisation de l'IA** : si l'IA a localisé l'élément, le sélecteur corrigé est enregistré sur le test et le coût IA est ajouté à l'exécution.
