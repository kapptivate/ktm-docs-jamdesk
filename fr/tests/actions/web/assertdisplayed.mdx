<Danger>
  **Obsolète.** Cette étape n'apparaît plus dans la palette d'étapes. Les tests existants qui l'utilisent continuent de fonctionner. Pour les nouveaux tests, utilisez [Vérifier l'élément](/fr/tests/actions/web/verifyelement) avec l'état **affiché**.
</Danger>

Vérifiez qu'un élément est visible sur la page, en échouant s'il n'apparaît pas dans le délai imparti.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel de l'élément qui doit être visible. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé lorsque l'IA est désactivée ou comme sélecteur enregistré. |
| Délai d'attente | Non | Durée d'attente avant l'échec. Par défaut : `30s`. |
| Utilisation de l'IA | Non | `inherit` (par défaut, suit la stratégie du test), `smart`, ou `always`. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Temps** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape. En cas d'échec, la durée reflète le délai d'attente complet.
- **Statut** : succès si l'élément est devenu visible dans le délai imparti, échec dans le cas contraire.
- **Capture d'écran** : prise pour l'état vérifié.
