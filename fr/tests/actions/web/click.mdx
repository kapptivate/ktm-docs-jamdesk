sidebarTitle: "Clic"
description: "Cliquez sur un bouton, un lien ou une entrée de menu dans un test web : l'IA le trouve d'après votre description, ou vous le ciblez avec un sélecteur."
---

Utilisez-la pour suivre un lien, envoyer un formulaire ou choisir une entrée dans un menu. Décrivez l'élément en langage naturel et l'IA le trouve, ou ciblez-le vous-même avec un sélecteur XPath ou CSS. Quand le clic doit changer la page, vérifiez le résultat avec [Vérifier l'élément](/fr/tests/actions/web/verifyelement).

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel de l'élément. L'IA l'utilise pour trouver l'élément, par exemple "Le bouton Se connecter dans le header". |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé quand l'IA est désactivée ou comme sélecteur enregistré. |
| Utilisation de l'IA | Non | `inherit` (par défaut, suit la stratégie du test), `smart` ou `always`. |
| Activer l'IA | Non | Quand désactivé, seul le sélecteur manuel est utilisé. Par défaut : activé. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

Le fonctionnement de la résolution IA de l'élément, et les cas de repli sur le sélecteur enregistré, sont détaillés dans [Sélecteurs IA](/fr/ai/selectors).

## Résultats et métriques

- **Temps d'exécution** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : succès, avertissement ou échec, avec le message d'erreur en cas d'échec.
- **Capture d'écran** : prise après le clic, pour voir la page vers laquelle il a mené.
- **Vérifications d'étape** : les vérifications d'URL, de temps de chargement et de durée de l'étape rapportent leurs valeurs attendues et réelles lorsqu'elles sont configurées.
- **Utilisation de l'IA** : si l'IA a localisé l'élément, le sélecteur corrigé est enregistré sur le test et le coût IA est ajouté à l'exécution.
