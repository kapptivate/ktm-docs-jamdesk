title: "Définir une variable locale dans un test web"
sidebarTitle: "Définir une variable locale"
description: Stockez une valeur dans une variable une seule fois et réutilisez-la dans toutes les étapes suivantes d'un test web.
---

Utilisez-la pour un nom d'utilisateur généré au début de l'exécution, une constante que vous ne voulez pas répéter, ou une valeur construite à partir d'autres variables. Pour capturer une valeur affichée sur la page, utilisez plutôt [Extraire une valeur](/fr/tests/actions/web/extractvalue).

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Nom de la variable | Oui | Nom de la variable à créer ou écraser. |
| Valeur | Oui | La valeur à stocker. Supporte le texte, d'autres variables et des fonctions comme le texte aléatoire. |

## Résultats et métriques

- **Variable** : disponible pour chaque étape ultérieure du test. Insérez-la partout où un champ supporte les variables.
- **Temps et statut** : enregistrés dans le résultat de l'étape comme pour toute autre étape.

Consultez [Variables](/fr/tests/variables) pour les types de variables et les fonctions utilisables dans les valeurs.
