<Danger>
  **Obsolète.** Cette étape n'apparaît plus dans la palette d'étapes. Les tests existants qui l'utilisent continuent de fonctionner. Pour les nouveaux tests, utilisez [Clic](/fr/tests/actions/web/click) pour ouvrir la liste déroulante et cliquer sur l'option, ce qui fonctionne aussi pour les listes déroulantes personnalisées (non natives).
</Danger>

Choisissez une option dans une liste déroulante native, la liste intégrée au navigateur (un élément HTML `<select>`), par son texte visible, sa position ou l'un de ses attributs.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel de l'élément select. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé lorsque l'IA est désactivée ou comme sélecteur enregistré. |
| Sélection de l'option par | Oui | `visible_text` (par défaut), `index`, ou `attribute`. |
| Valeur | Quand by est `visible_text` | Le texte visible de l'option. |
| Index | Quand by est `index` | La position de l'option, à partir de 0. |
| Nom et valeur de l'attribut | Quand by est `attribute` | L'attribut HTML à faire correspondre, par exemple `value` = `FR`. |
| Utilisation de l'IA | Non | `inherit` (par défaut, suit la stratégie du test), `smart`, ou `always`. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Temps** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : échec si l'élément ou l'option demandée ne peut pas être trouvé.
- **Capture d'écran** : prise après la sélection.
