---
title: "Survoler un élément dans un test web"
sidebarTitle: "Survol"
description: Placez la souris sur un élément, sans cliquer, pour révéler des menus, des infobulles et d'autres effets de survol.
---

Utilisez-le pour tout ce qui n'apparaît que sous la souris : un menu déroulant qui s'ouvre au survol, une infobulle, un bouton qui change d'aspect. Choisissez ensuite une entrée du menu avec un step [Click](/fr/tests/actions/web/click), ou vérifiez que l'infobulle est apparue avec [Verify element](/fr/tests/actions/web/verifyelement).

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément cible | Oui, sauf si un selector manuel est défini | Description en langage naturel de l'élément. L'IA l'utilise pour trouver l'élément. |
| Selector manuel | Non | Selector XPath ou CSS, utilisé quand l'IA est désactivée ou comme selector enregistré. |
| Utilisation de l'IA | Non | `inherit` (par défaut, suit la stratégie du test), `smart` ou `always`. |
| Activer l'IA | Non | Quand désactivé, seul le selector manuel est utilisé. Par défaut : activé. |
| Ignorer l'erreur sur ce step | Non | L'exécution continue avec le step suivant si celui-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Temps d'exécution** : début, fin et durée (en secondes) enregistrés dans le résultat du step.
- **Statut** : succès, avertissement ou échec, avec le message d'erreur en cas d'échec.
- **Capture d'écran** : prise pendant que l'état de survol est actif, montrant ce qu'il a révélé.
- **Utilisation de l'IA** : si l'IA a localisé l'élément, le selector corrigé est enregistré sur le test et le coût IA est ajouté à l'exécution.
