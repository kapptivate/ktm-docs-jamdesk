---

Utilisez-la pour gérer un parcours qu'aucune étape intégrée ne couvre, calculer une valeur, ou envoyer une métrique personnalisée vers les Analytiques. Le script s'exécute sur le device du test, dans la même session que les autres étapes.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Nom de l'étape | Non | Le nom affiché pour cette étape dans le builder et dans les résultats. |
| Script | Oui | Code JavaScript, édité dans une fenêtre modale dédiée. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si le script lève une erreur. Par défaut : désactivé. |

Pour piloter l'application depuis le script, utilisez l'objet `browser` : il donne accès à toute l'API WebdriverIO (une librairie JavaScript d'automatisation des devices et des navigateurs). Les helpers `test` couvrent le reste, par exemple :

```javascript
// Push a custom metric to Analytics
test.metrics.create("checkout", { basket_total: 39.98 }, { currency: "EUR" });
```

## Résultats et métriques

- **Timing** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : échec si le script lève une erreur, succès sinon.
- **Sortie** : tout ce que le script journalise est disponible dans la sortie de l'étape pour le débogage.
- **Métriques personnalisées** : les métriques créées avec `test.metrics.create(measurement, fields, tags)` remontent vers les Analytiques comme toute métrique intégrée.
