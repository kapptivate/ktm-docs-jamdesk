  **Déprécié.** Cette étape n'apparaît plus dans la palette d'étapes. Les tests existants qui l'utilisent continuent de fonctionner. Pour les nouveaux tests, utilisez [Vérifier l'élément](/fr/tests/actions/smartphone/verifyelement) avec l'état **affiché**.
</Danger>

L'étape attend que l'élément apparaisse et échoue s'il n'est toujours pas visible à la fin du délai.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel de l'élément qui doit être visible. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé lorsque l'IA est désactivée ou comme sélecteur enregistré. |
| Timeout | Non | Combien de temps attendre l'élément avant l'échec. Par défaut : `30s`. |
| Utilisation de l'IA | Non | `inherit` (par défaut, suit la stratégie du test), `smart` ou `always`. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Timing** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape. En cas d'échec, la durée reflète la totalité du timeout.
- **Statut** : succès si l'élément est devenu visible dans le délai imparti, échec sinon.
- **Capture d'écran** : prise pour l'état vérifié.
