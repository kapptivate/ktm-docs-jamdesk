---

Utilisez-la quand le parcours passe par un email : confirmation de compte, réinitialisation de mot de passe, connexion par lien magique. L'étape attend l'email, demande à l'IA le lien qui correspond à votre intention, et le stocke dans une variable pour les étapes suivantes.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Email de réception du lien | Oui | L'adresse de la boîte de test qui doit recevoir l'email contenant le lien. |
| Variable | Oui | Nom de la variable qui reçoit le lien. Par défaut : `LienMail`. |
| Intention | Non | Quel lien l'IA doit extraire. Par défaut : `The first link in the text`. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si aucun lien n'est trouvé. Par défaut : désactivé. |

Utilisez l'intention pour désambiguïser les emails contenant plusieurs liens : "The password reset link", "The link in the Confirm my account button".

## Résultats et métriques

- **Variable** : le lien extrait est stocké dans la variable. Ouvrez-le avec une étape de navigation pour continuer le flux.
- **Timing** : début, fin et durée (en secondes). La durée inclut l'attente de réception de l'email.
- **Statut** : échec si aucun email n'arrive ou si l'IA ne trouve pas de lien correspondant à l'intention.
- **Utilisation de l'IA** : le coût IA de l'extraction est ajouté à l'exécution.

Consultez [Email et SMS dans les tests](/fr/tests/email-sms) pour comprendre le fonctionnement des boîtes de test.
