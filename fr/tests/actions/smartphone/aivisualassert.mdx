---

Vérifiez ce qu'un sélecteur ne peut pas exprimer : "le carrousel d'onboarding affiche 3 points", "le total du panier correspond à la somme des articles", "aucune bannière d'erreur n'est visible". L'IA examine l'écran actuel et juge si votre assertion est vraie.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Assertion | Oui | Ce qui doit être vrai, en langage naturel. Par exemple : "The cart shows 2 items and a total of 39,98 €". Supporte les variables. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Timing** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : succès lorsque l'IA juge l'assertion vraie sur l'écran actuel, échec sinon, avec l'explication de l'IA dans le résultat.
- **Capture d'écran** : prise pour l'état vérifié, afin que vous puissiez examiner ce que l'IA a évalué.
- **Utilisation de l'IA** : le coût IA de l'évaluation est ajouté à l'exécution.

Pour rédiger des assertions fiables, consultez [Vérifier avec l'IA](/fr/ai/verify-with-ai).
