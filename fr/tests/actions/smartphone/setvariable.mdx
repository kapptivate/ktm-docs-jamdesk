---

Utilisez-la pour un nom d'utilisateur généré au début de l'exécution, une constante que vous ne voulez pas répéter, ou une valeur construite à partir d'autres variables.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Nom de la variable | Oui | Nom de la variable à créer ou écraser. |
| Valeur | Oui | La valeur à stocker. Supporte le texte, d'autres variables et des fonctions comme le texte aléatoire. |

## Résultats et métriques

- **Variable** : disponible pour toutes les étapes suivantes du test. Insérez-la partout où un champ supporte les variables.
- **Timing et statut** : enregistrés dans le résultat de l'étape comme toute autre étape.

Consultez [Variables](/fr/tests/variables) pour les types de variables et les fonctions utilisables dans les valeurs.
