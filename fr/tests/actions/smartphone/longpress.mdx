---

Utilisez-la pour ouvrir le menu contextuel d'un élément de liste, saisir une poignée de déplacement, ou déclencher toute autre action que l'application prévoit sur un appui long. Ajoutez ensuite une étape [Toucher](/fr/tests/actions/smartphone/tap) pour choisir une action dans le menu qui s'ouvre.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel de l'élément. L'IA l'utilise pour trouver l'élément. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé lorsque l'IA est désactivée ou comme sélecteur enregistré. |
| Utilisation de l'IA | Non | `smart` (par défaut), `always` ou `inherit`. |
| Activer l'IA | Non | Par défaut : désactivé. Activez-le pour localiser l'élément à partir de la description. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Timing** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : succès, avertissement ou échec, avec le message d'erreur en cas d'échec.
- **Capture d'écran** : prise après l'appui long, montrant généralement les actions contextuelles ouvertes.
- **Utilisation de l'IA** : si l'IA a localisé l'élément, le sélecteur corrigé est enregistré sur le test et le coût IA est ajouté à l'exécution.
