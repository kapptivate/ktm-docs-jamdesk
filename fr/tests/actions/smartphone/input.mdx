Une même valeur peut mélanger les trois : la même étape se connecte alors avec un compte enregistré, ou s'inscrit avec un email aléatoire différent à chaque exécution.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description en langage naturel du champ. L'IA l'utilise pour trouver l'élément. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS, utilisé lorsque l'IA est désactivée ou comme sélecteur enregistré. |
| Valeur | Oui | Texte à saisir. Supporte les variables et les fonctions comme le texte aléatoire. |
| Utilisation de l'IA | Non | `inherit` (par défaut, suit la stratégie du test), `smart` ou `always`. |
| Activer l'IA | Non | Lorsque désactivé, seul le sélecteur manuel est utilisé. Par défaut : activé. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Timing** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : succès, avertissement ou échec, avec le message d'erreur en cas d'échec.
- **Capture d'écran** : prise après l'exécution de l'étape.
- **Utilisation de l'IA** : si l'IA a localisé l'élément, le sélecteur corrigé est enregistré sur le test et le coût IA est ajouté à l'exécution.
