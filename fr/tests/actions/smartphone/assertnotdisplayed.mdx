<Danger>
  **Déprécié.** Cette étape n'apparaît plus dans la palette d'étapes. Les tests existants qui l'utilisent continuent de fonctionner. Pour les nouveaux tests, utilisez [Vérifier l'élément](/fr/tests/actions/smartphone/verifyelement) avec la condition **n'est pas** et l'état **affiché**.
</Danger>

Utilisez-la pour ce qui ne doit pas être à l'écran : une bannière d'erreur qui ne devrait pas s'afficher, un spinner qui devrait avoir disparu.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Élément ciblé | Oui, sauf si un sélecteur manuel est défini | Description de l'élément qui ne doit pas être visible. |
| Sélecteur manuel | Non | Sélecteur XPath ou CSS de l'élément qui ne doit pas être visible. |
| Timeout | Non | Combien de temps attendre que l'élément disparaisse avant l'échec. Par défaut : `30s`. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si celle-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Timing** : début, fin et durée (en secondes) enregistrés dans le résultat de l'étape.
- **Statut** : succès si l'élément est absent ou masqué dans le délai imparti, échec s'il reste visible.
- **Capture d'écran** : prise pour l'état vérifié.
