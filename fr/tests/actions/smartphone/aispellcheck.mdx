---
title: "Vérifier l'orthographe (IA) dans un test smartphone"
sidebarTitle: "Vérification orthographique (IA)"
description: Repérez les fautes de frappe et de grammaire d'un écran de l'application avant vos utilisateurs, grâce à une relecture IA du texte visible.
---

Ajoutez-le sur les écrans chargés en texte, ou pour vérifier une version traduite de l'application. L'IA lit le texte visible sur l'écran actuel et signale tout ce qui semble incorrect dans la langue que vous indiquez.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Langue | Oui | La langue dans laquelle le texte visible est censé être rédigé (par exemple `French`). |
| Ignorer l'erreur sur ce step | Non | L'exécution continue avec le step suivant si celui-ci échoue. Par défaut : désactivé. |

## Résultats et métriques

- **Timing** : début, fin et durée (en secondes) enregistrés dans le résultat du step.
- **Statut** : échec lorsque l'IA trouve des problèmes d'orthographe ou de grammaire dans le texte visible, avec les problèmes listés dans le résultat.
- **Capture d'écran** : prise pour l'état vérifié, afin que vous puissiez voir exactement ce qui a été contrôlé.
- **Utilisation de l'IA** : le coût IA de la vérification est ajouté à l'exécution.

Pour comprendre le fonctionnement de la vérification et interpréter les résultats, consultez [Spell check](/fr/ai/spell-check).
