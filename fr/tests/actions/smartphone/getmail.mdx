---

Utilisez-la pour tout email que votre application doit envoyer : un message de bienvenue, une confirmation de commande, une facture.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Boîte mail | Oui | L'adresse de la boîte de test qui doit recevoir l'email. |
| Ignorer les erreurs sur cette étape | Non | L'exécution continue avec l'étape suivante si aucun email n'arrive. Par défaut : désactivé. |

## Résultats et métriques

- **Contenu de l'email** : l'email reçu est attaché au résultat de l'étape, vous pouvez le consulter lors de la revue de l'exécution.
- **Timing** : début, fin et durée (en secondes). La durée indique le temps de livraison.
- **Statut** : échec si aucun email n'arrive dans la boîte.

Consultez [Email et SMS dans les tests](/fr/tests/email-sms) pour comprendre le fonctionnement des boîtes de test et leur adressage.
