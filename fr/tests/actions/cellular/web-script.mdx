---
title: "Exécuter un scénario web via la connexion SIM"
sidebarTitle: "Web Script"
description: "Exécutez un parcours web scripté avec son trafic routé via la connexion data de la SIM, et chronométrez chaque étape sur le réseau mobile."
---

Scriptez en JavaScript un parcours comme une connexion, une recherche ou un paiement (chargements de pages, clics, remplissage de formulaires). Le trafic passe par la SIM : chaque étape est mesurée telle qu'un abonné la vivrait sur le réseau mobile.

## Paramètres

| Paramètre | Requis | Description |
| ----------- | -------- | ------------- |
| Script | Oui | Le scénario web JavaScript à exécuter. |
| Asynchrone | Non | Exécuter le script sans bloquer les actions suivantes. Par défaut : désactivé. |

Ainsi que les [paramètres de connexion](/fr/tests/actions/cellular/overview#paramètres-de-connexion) partagés.

## Résultats et métriques

Le rapport contient une entrée par étape du script : statut, durée, captures d'écran et métriques personnalisées créées par le script. Les durées et statuts des étapes alimentent Analytics comme les autres actions, étiquetées par antenne et technologie d'accès, pour que vous puissiez suivre chaque étape du parcours sur le réseau cellulaire.
