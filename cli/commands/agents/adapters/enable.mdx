Start a controllable adapter on an agent (no agent restart)

## Usage

```bash
ktm agents adapters enable <adapter> [flags]
```

## Examples

```bash
ktm agents adapters enable adb_bridge --agent phone-hub-01
```

## Arguments

| Argument | Required |
| --- | --- |
| `adapter` | Yes |

## Details

Starts an adapter on an agent, without restarting the agent. Enabling an
adapter that is already running reports success and changes nothing.

The change is ephemeral: after an agent restart, the agent's own configuration
decides again.
