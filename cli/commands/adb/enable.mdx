Turn on the ADB bridge on an agent (no agent restart)

## Usage

```bash
ktm adb enable [flags]
```

## Examples

```bash
ktm adb enable --agent phone-hub-01
```

## Details

Starts the ADB bridge on an agent so its phones accept 'ktm adb connect'. The toggle is ephemeral: after an agent restart, the agent's own configuration decides again.
